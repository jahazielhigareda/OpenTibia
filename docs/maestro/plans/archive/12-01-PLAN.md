# Phase 12: Network Protocol & Data Structures

## Objective
Define the core data structures and protocol packets required for the 8.60 login and game flow.

## Key Files & Context
- `OpenTibia.Client\ClientState.cs`: New enum for client states.
- `OpenTibia.Client\Network\RawMessageCollection.cs`: New class for raw packet delivery.
- `OpenTibia.Client\Network\Packets\Outgoing\LoginOutgoingPacket.cs`: New class for 8.60 login payload.
- `OpenTibia.Network\Packets\Incoming\World\`: New incoming packets (0x1F, 0x15, 0x0F).
