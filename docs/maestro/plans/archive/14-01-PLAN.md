# Phase 14: User Interface & State Machine

## Objective
Create the user-facing Login screen and implement the main game loop logic to transition between Login and In-Game states.

## Key Files & Context
- `OpenTibia.Client\UI\LoginScreen.cs`: New class for Raylib login UI.
- `OpenTibia.Client\Program.cs`: Update main loop for state management.

## Implementation Steps

### 1. Implement Login Screen
- Create `OpenTibia.Client\UI\LoginScreen.cs`.
- Implement text input for Host, Port, Account, and Password.
- Implement "Connect" button and Enter key handling.
- Expose `OnConnect` event.

### 2. Update Program.cs
- Instantiate `LoginScreen`.
- Implement state machine in `while (!Raylib.WindowShouldClose())`:
    - `Login`, `Connecting`, `LoggingIn`, `EnteringWorld`: Show `LoginScreen` and status bar.
    - `InGame`: Render world, update camera, and handle game input.
- Wire `loginScreen.OnConnect` to `server.Connect`.

## Verification & Testing
- Compile project.
- Launch client and verify Login UI appears.
- (Manual) Verify fields can be typed into.
