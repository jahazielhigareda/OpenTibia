# Phase 13: Logic & Connectivity

## Objective
Implement the connection management, login logic, and command handling for the protocol 8.60 transition.

## Key Files & Context
- `OpenTibia.Client\Network\ClientConnection.cs`: Implement unencrypted sending.
- `OpenTibia.Client\ClientServer.cs`: Implement connection/login flow.
- `OpenTibia.Client\Network\IncomingCommandHandler.cs`: Register new packets/commands.
- `OpenTibia.Client\Commands\Incoming\`: Implement `ConnectionInfoCommand`, `PendingStateCommand`, and `EnterWorldCommand`.

## Implementation Steps

### 1. Extend ClientConnection
- Add `_sendingRaw` flag.
- Override `Envelope` to return bytes as-is if `_sendingRaw` is true.
- Implement `SendLoginPayload(byte[] payload)`.

### 2. Implement Incoming Commands
- Create `OpenTibia.Client\Commands\Incoming\ConnectionInfoCommand.cs`.
- Create `OpenTibia.Client\Commands\Incoming\PendingStateCommand.cs`.
- Create `OpenTibia.Client\Commands\Incoming\EnterWorldCommand.cs`.

### 3. Update ClientServer
- Add credential fields (`_account`, `_password`, etc.).
- Update `Connect` to accept credentials and wait for potential challenge.
- Implement `SendLogin()`.

### 4. Update IncomingCommandHandler
- Add `using` for new packet/command types.
- Register new pairs in constructor (0x1F, 0x15, 0x0F).

## Verification & Testing
- Compile project.
- Verify that `ClientConnection` can still handle normal XTEA traffic.
