# Phase 11: Architectural Polish & Fixes

## Objective
Resolve 7 specific architectural and implementation issues in the OpenTibia Client to improve decoupling, stability, and code quality.

## Key Files & Context
- `OpenTibia.Game.Common\Common\IServer.cs`: Redundant declarations.
- `OpenTibia.Client\Network\ClientPacketReader.cs`: Logging and registration.
- `OpenTibia.Client\Network\IncomingCommandHandler.cs`: Unified registration.
- `OpenTibia.Client\Commands\Incoming\*.cs`: Context usage.
- `OpenTibia.Client\LocalGameState.cs`: Constructor cleanup.
- `OpenTibia.Client\OpenTibia.Client.csproj`: Redundant reference.

## Implementation Steps

### 1. Fix Redundant Declarations (FIX-02)
- Modify `OpenTibia.Game.Common\Common\IServer.cs`:
    - Remove `Start()`, `Stop()`, `Pause()`, `Continue()`, `Post()`, `QueueForExecution()`.
    - Remove `ICommandHandlerCollection CommandHandlers { get; set; }`.

### 2. Decouple InputManager & Add Walk (FIX-04)
- (Already mostly done, verify and ensure `IClientServer` has `Walk` and `InputManager` uses the interface).
- Ensure `ClientServer` implements `Walk(Direction)` as defined in `IClientServer`.

### 3. Unified Registration System (FIX-07)
- Modify `OpenTibia.Client\Network\IncomingCommandHandler.cs`:
    - Update `Register<TPacket, TCommand>()` to `Register<TPacket, TCommand>(byte packetId)`.
    - Call `ClientPacketReader.Register(packetId, typeof(TPacket))` inside `Register`.
    - Update constructor with packet IDs:
        - `SelfAppearIncomingPacket`: `0x0A`
        - `MapDescriptionIncomingPacket`: `0x64`
        - `CreatureMoveIncomingPacket`: `0x6D`
- Modify `OpenTibia.Client\Program.cs`:
    - Remove manual `ClientPacketReader.Register` calls.

### 4. Logging in ClientPacketReader (FIX-03)
- Modify `OpenTibia.Client\Network\ClientPacketReader.cs`:
    - Use `Context.Current?.Server?.Logger?.WriteLine` for unknown packet IDs.
    - Fallback to `Console.Error.WriteLine` if context/logger is null.

### 5. Context Usage in Commands (FIX-01)
- Modify `OpenTibia.Client\ClientContext.cs`:
    - Ensure `Current` static property is used.
- Modify incoming commands in `OpenTibia.Client\Commands\Incoming\`:
    - Use `ClientContext.Current` instead of `Context.Current as ClientContext`.
    - Affected: `CreatureMoveCommand.cs`, `MapDescriptionCommand.cs`, `SelfAppearCommand.cs`.
- Modify `OpenTibia.Client\Commands\UpdatePlayerHealthCommand.cs`:
    - Use `ClientContext.Current`.

### 6. LocalGameState Cleanup (FIX-05)
- Modify `OpenTibia.Client\LocalGameState.cs`:
    - Remove initial tile at (0,0,0) from constructor.

### 7. Project Reference Cleanup (FIX-06)
- Modify `OpenTibia.Client\OpenTibia.Client.csproj`:
    - Remove `<ProjectReference Include="..\OpenTibia.Game\OpenTibia.Game.csproj" />`.

## Verification & Testing
- Build the solution: `dotnet build`.
- Run existing tests: `dotnet test`.
- Manually verify the client still starts up correctly (though we can't fully run it without a server).
