# Milestone v1.0: Foundation & Core Logic

**Status:** ✅ SHIPPED 2026-04-21
**Phases:** 01-10
**Total Plans:** 18

## Overview

Milestone 1.0 focuses on building the foundational client architecture using Raylib and the OpenTibia handler-driven pattern. It establishes the core game loop, asset pipeline, and basic world rendering with keyboard input.

## Milestone Summary

**Key Decisions:**
- Use `MainThreadDispatcher` for Raylib compatibility.
- Scale map data using `Dictionary<Position, Tile>` for non-contiguous map support.
- Decouple `ClientServer` from `IServer` to focus on client-side requirements.

**Issues Resolved:**
- Redundant project path prefix in asset loading.
- Asynchronous sprite loading race conditions.
- Test suite compilation failures after architectural changes.

**Technical Debt Incurred:**
- Creature rendering uses placeholder circles.
- RSA/Adler32 handshake logic remains a stub.
- Player movement command dispatch is a logging stub.
