# Phase 3: Network & Command Handlers
Plan for integrating server communication and mapping incoming packets to the local game state.

## Wave 1: Foundation & Secure Handshake
- [ ] Implement `OpenTibia.Client/Network/ClientConnection.cs` for secure TCP connection and handshake.
- [ ] Integrate RSA/XTEA encryption from `OpenTibia.Security`.
- [ ] Implement `OpenTibia.Client/ClientServer.cs` to handle the connection lifecycle.

## Wave 2: MVP Packets
- [ ] Implement `OpenTibia.Client/Network/ClientPacketReader.cs` for packet ID identification.
- [ ] Implement MVP packets: `SelfAppear` (0x0A), `MapDescription` (0x64), and `CreatureMove` (0x6D).

## Wave 3: Incoming Commands & Wiring
- [ ] Implement `IncomingCommands` for each MVP packet.
- [ ] Wire the connection to dispatch these commands to the `ClientContext.Dispatcher`.
- [ ] Final visual check: connect to a mock/local server and verify the map updates.
